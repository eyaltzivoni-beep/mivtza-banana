# מבצע בננה 🍌

אתר משחק לנוער: משימה סודית יומית ומתרגם רגשות דרמטי. בלי הרשמה: נכנסים עם קישור או ברקוד.

## העלאה לאוויר (פעם אחת, כ-15 דקות)

1. **GitHub:** פתחו חשבון ב-github.com ← New repository ← שם: `mivtza-banana` ← Create.
   בדף הריק לחצו "uploading an existing file" וגררו לשם את **כל התוכן** של התיקייה הזו (כולל התיקיות `api`, `lib`, `public`) ← Commit.
2. **Vercel:** היכנסו ל-vercel.com עם חשבון ה-GitHub ← Add New ← Project ← בחרו את `mivtza-banana` ← Deploy.
3. **מסד נתונים:** בפרויקט ב-Vercel ← לשונית Storage:
   - Create ← **Upstash for Redis** (חינם) ← Connect לפרויקט.
   - Create ← **Blob** (ציבורי, Public) ← Connect לפרויקט.
4. **מפתח AI:** ב-console.anthropic.com צרו API Key והגדירו תקרת הוצאה חודשית (Limits).
   ב-Vercel ← Settings ← Environment Variables ← הוסיפו `ANTHROPIC_API_KEY` עם המפתח.
5. Deployments ← שלוש נקודות ליד הגרסה האחרונה ← **Redeploy**.

הכתובת תהיה משהו כמו `https://mivtza-banana.vercel.app`. בתוך האתר, בלשונית "דירוג" או בכפתור "➕ הזמנה", יש ברקוד וקישור שמכניסים ישר לקבוצה.

## המרדנים
בכתובת `/hamardanim` (וגם בכפתור 🔥 באתר) נמצאים כל המשחקים של המרדנים: לומדים, דו-קרב (כולל אונליין), קטלו אותי, בדיחות, קסמים, משחקים, כלים, קטגוריות, סטודיו, רַץ, פלאות, כיכר, מלון ומצחיקון.
ה-AI שלהם עובר דרך אותו מפתח של האתר, והדו-קרב האונליין שומר את הזירה באותו Redis. אין צורך ב-Firebase.

## הגדרות אופציונליות (Environment Variables)
- `AI_DAILY_LIMIT`: מספר בקשות AI ליום לכל מכשיר/רשת (ברירת מחדל 60).
- `AI_GLOBAL_DAILY_LIMIT`: תקרת בקשות AI ליום לכל האתר (ברירת מחדל 3000). שומר על התקציב.
- `CLAUDE_MODEL`: דגם ה-AI של מבצע בננה (ברירת מחדל `claude-haiku-5-5`, המהיר והזול).
- `CLAUDE_MODEL_GAMES`: דגם ה-AI של המרדנים (ברירת מחדל זהה). אפשר לשים `claude-sonnet-5-5` לבדיחות חדות יותר, בעלות גבוהה יותר.

## בטיחות
- כל תמונה או סרטון נבדקים ע"י AI לפני פרסום, ונחסמים אם הם לא מתאימים.
- משפטים, שמות וכיתובים עוברים סינון.
- רק מי שיש לו את קוד החדר רואה את הפוסטים של הקבוצה.
- כל שחקן יכול לדווח על פוסט, והוא מוסתר מיד לכולם.

## אפליקציית אנדרואיד (APK)

אחרי שהאתר באוויר:
1. ב-GitHub, במאגר: Settings ← Secrets and variables ← Actions ← לשונית **Variables** ← New variable:
   שם `SITE_URL`, ערך הכתובת של האתר (למשל `https://mivtza-banana.vercel.app`).
2. לשונית **Actions** ← "Build Android APK" ← **Run workflow**.
3. אחרי כ-5 דקות, בתוך הריצה, בתחתית תחת Artifacts: מורידים את `mivtza-banana-apk` (קובץ zip עם ה-APK בפנים).
4. שולחים את ה-APK לטלפון ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

האפליקציה פותחת את האתר במסך מלא, כך שכל עדכון לאתר מגיע לאפליקציה בלי להתקין מחדש.
זו גרסת debug: מתאימה להתקנה ישירה, לא לחנות Google Play.

**דרך בלי APK:** פותחים את האתר בכרום בטלפון ← תפריט ⋮ ← "הוספה למסך הבית". מקבלים אייקון ואפליקציה במסך מלא.
